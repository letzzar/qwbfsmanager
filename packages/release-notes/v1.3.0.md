QWBFS Manager 1.3.0 is a port of the original [QWBFS Manager](https://github.com/pasnox/qwbfsmanager) by Filipe Azevedo (pasnox) to modern operating systems. The last original release, 1.2.6, dates from 2016 and could no longer be built (Qt 4/5, qmake, OpenSSL 0.9/1.0, UDisks 1).

Port by [letzzar](https://github.com/letzzar) and Claude (Anthropic).

## Downloads

| System | File |
|---|---|
| macOS 12+ (Apple Silicon **and** Intel, universal) | `QWBFSManager-1.3.0-macos-arm64-x86_64.dmg` |
| Windows 10/11 x64 | `QWBFSManager-windows-x64.zip` (unzip and run `qwbfsmanager.exe`) |
| Linux x86_64 (binary built on Ubuntu 24.04, needs Qt 6 from the distribution) | `QWBFSManager-linux-x86_64.tar.gz` |

> macOS: the app is ad-hoc signed, not notarized by Apple. On first launch macOS will block it: open *System Settings → Privacy & Security* and click *Open Anyway*, or run `xattr -dr com.apple.quarantine /Applications/QWBFSManager.app`.
> Reading and writing a WBFS partition needs raw access to the device: you may need to run the application as administrator/root.

## What changed

### Port to modern systems
- **Qt 6 and CMake** replace Qt 4/qmake. Every Qt API removed in Qt 6 was ported (style options, `QDesktopWidget`, `QRegExp`, `qSort`, timers, combo box signals...).
- **Native Apple Silicon build** and a universal DMG (arm64 + x86_64), self contained, with its `Info.plist`.
- macOS: the Carbon `FSGetVolumeInfo` API (deprecated since 10.8) was replaced by `statfs`.
- Linux: the removed UDisks 1 D-Bus service was replaced by the mounted volumes and the current udev properties; Qt DBus is no longer needed.
- Windows: builds with MSVC (the original code only built with MinGW).
- **No more OpenSSL**: the code using it was never called.
- The Fresh library (git submodule) is now vendored: only the used subset, ported to Qt 6 (`3rdparty/fresh`).
- The update checker now reads the releases of this repository.

### Fixes
- Copying a disc image used a 5 MB buffer on the worker thread stack (512 KB on macOS): it could crash. The byte counter was an `int`: overflow on images bigger than 2 GiB (Wii images are 4.7 GB).
- Version numbers were never split by the version comparator.
- Three signal/slot connections silently broken with Qt 6.

### Refreshed interface
- New line icons ([Lucide](https://lucide.dev)) following the light/dark system theme.
- New application icon, splash screen and cover placeholders.
- Flatter toolbar, rounded notification banner using the system accent color, new dock panel buttons.
- The PayPal donation button was removed (broken link).

### Build and continuous integration
- GitHub Actions builds Linux, Windows and macOS on every push and publishes the release on `v*` tags.
- `packages/macos/make-dmg.sh` builds the `.app` and the `.dmg` locally.

## En español

QWBFS Manager 1.3.0 es un port a sistemas operativos actuales del [QWBFS Manager original](https://github.com/pasnox/qwbfsmanager) de Filipe Azevedo (pasnox), cuya última versión (1.2.6, de 2016) ya no se podía compilar.

Port realizado por [letzzar](https://github.com/letzzar) y Claude (Anthropic).

- **Qt 6 y CMake**, compilación **nativa para Apple Silicon** y DMG universal (ARM + Intel, macOS 12+), Windows con MSVC y Linux actual.
- Sin OpenSSL ni submódulos; APIs obsoletas de macOS y Linux sustituidas por las actuales.
- Corregidos: un posible cierre al copiar imágenes (buffer de 5 MB en la pila del hilo), el desbordamiento con imágenes de más de 2 GB y el comparador de versiones.
- Interfaz renovada: iconos de línea que siguen el modo claro/oscuro, nuevo icono de la app, nueva pantalla de inicio y paneles más limpios. Eliminado el botón de donación (enlace roto).
